# Final analysis tables

This directory contains the tables and summary from the submission rerun. The
tab-separated files record the benchmark, ablation, sensitivity, applicability,
and provenance results. `RESULTS_FOR_MANUSCRIPT.md` summarizes which findings
were confirmed, changed, or qualified by the rerun.

The results are specific to the datasets, splits, and evaluation procedures
described in the data card and reproducibility documentation. They should not
be interpreted as evidence of generalization to unseen proteins.
